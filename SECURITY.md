# Security Policy

## Supported version

The actively maintained compatibility release is:

| Version | Supported |
| --- | --- |
| 1.6.4 | Yes |
| Earlier versions | No |

## Reporting a security issue

Please do not publish sensitive security details in a public GitHub Issue.

For a normal bug, crash, package-compatibility problem or feature request, use the repository Issues section.

If you believe you have found a security-related problem in the ChayahLabs compatibility changes, contact ChayahLabs privately through the contact methods available on the GitHub profile and include:

- A clear description of the issue
- The affected PS4PKGViewer version
- Reproduction steps
- Relevant logs
- The potential impact

Do not send copyrighted PKG files, credentials, passcodes or other sensitive material.

## Scope

This policy covers the ChayahLabs compatibility work distributed through this repository. Third-party projects and services referenced by PS4PKGViewer remain under the responsibility of their respective maintainers.
