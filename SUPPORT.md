# Support

## Bug reports

For PS4PKGViewer bugs and package-compatibility problems, open a GitHub Issue using the **Bug report** template.

Useful information includes:

- Title ID / Content ID
- Base game, update or DLC
- Official PKG or Fake PKG
- APP_VER
- VERSION
- SYSTEM_VER
- Exact error message
- Whether **List Contents** succeeds or fails
- Relevant lines from `%TEMP%\PS4PKGViewer_ChayahFallback.log`
- Reproduction steps

Please do not upload copyrighted game PKG files.

## Feature requests

New ideas and compatibility improvements are welcome. Open an Issue using the **Feature request** template and describe the expected behavior and use case.

## Third-party components

Questions specifically about LibOrbisPkg, PkgTool, ORBISPatches, Sony services or other third-party projects may need to be directed to their respective maintainers.
